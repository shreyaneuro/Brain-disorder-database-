# Brain Disorder Database

A neuroscience educational repository covering major neurological disorders.

## Diseases Included

- Alzheimer's Disease
- Parkinson's Disease
- Huntington's Disease
- ALS
- Epilepsy
- Stroke
- Multiple Sclerosis
- Autism Spectrum Disorder
- ADHD
- Brain Tumors
- Depression

Each chapter includes:
- Definition
- Epidemiology
- Risk Factors
- Brain Regions
- Pathophysiology
- Genetics
- Symptoms
- Diagnosis
- Neuroimaging
- Biomarkers
- Treatment
- Latest Research
